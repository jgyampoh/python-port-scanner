# Python Network Port Scanner

A Python-based TCP port scanner developed as part of my cybersecurity portfolio.

## Project Status

🚧 Currently under development.

## Objective

The goal of this project is to learn and demonstrate fundamental networking and cybersecurity concepts including:

- TCP/IP networking
- Ports and services
- Python socket programming
- Network reconnaissance
- Error handling
- Command-line tools

## Ethical Use

This project is intended for educational purposes and authorized security testing only. Only scan systems that you own or have explicit permission to test.
